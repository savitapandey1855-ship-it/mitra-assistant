Mitra Float — Android pe floating assistant

Ye guide aapko ek aisa chhota assistant banane me madad karega jo screen ke upar float karta hai, aapki awaaz sunta hai, jahan kaho wahan click/type karta hai, aur khud email bhi likh sakta hai.

Sach baat pehle: ye us video wale 'Bluey' ka sabse advanced hissa hai — screen control + automation + AI. Ye ek raat me nahi banega. Hum ise 4 Levels me banayenge. Har level ke baad kuch na kuch kaam karne lagega. Aaram se, ek-ek karke.

Kaunse app se banayenge?

Hum 'Automate' (LlamaLab) naam ka free app use karenge. Isme pehle se hi sab kuch hai — floating button, awaaz sunna, bolna, tap/type karna, email bhejna, aur internet se AI (Gemini) — aur code likhne ki zaroorat nahi. Sab kuch boxes (blocks) jodkar banta hai.

Level 0 — Taiyari (permissions)

  • Play Store se 'Automate' (LlamaLab) install karo.
  • Jab app maange, 'Display over other apps' permission do — ye float karne ke liye zaroori hai.
  • Accessibility permission bhi do (Automate ke andar Settings me jaake 'Automate accessibility service' ON karo) — ye 'kahin bhi tap/type' karne ke liye chahiye.
  • Microphone aur Internet permission do.
  • Ek free Gemini API key banao: aistudio.google.com/app/apikey — Google se login karke 'Create API key'. Ye Level 4 (email/AI) ke liye chahiye.
API key aapki personal chaabi hai — kisi ko na do, kisi website pe public na karo. Wo sirf aapke phone me Automate ke andar rahegi.

Level 1 — Floating button jo sunta hai

Sabse pehle ek button jo screen pe tairta rahe, aur dabane pe aapki baat sune. Naya flow banao aur ye blocks jodo:

Flow beginning  >  Floating button show  >  Speech recognition  >  Speak  >  Go to (wapas 'Floating button show' pe)
  • Floating button show: koi icon aur rang chuno. Ye button screen pe dikhega.
  • Speech recognition: Language 'English (India)' ya 'Hindi' chuno. Jo sunega wo ek variable me aayega (maan lo 'spoken').
  • Speak: text me likho — Tumne kaha: {spoken} — taaki assistant bol kar bata de ki usne kya suna.
  • Go to: wapas 'Floating button show' pe le jao, taaki button phir se dikhe (loop).

Save karke Start dabao. Ab screen pe chhota button aayega — tap karo, bolo, aur Mitra aapki baat dohraayega. Ye Level 1 hai, mubarak ho!

Level 2 — Jo bolu, wo kare

Ab 'spoken' ke hisaab se kaam karvayenge. Iske liye 'Expression true' ya 'Dialog choice' block se check karo ki baat me kya hai, phir us hisaab se kaam karo:

  • 'open youtube' jaisi baat me -> App start block (YouTube kholo).
  • 'type ...' me -> Key send characters block (jo bolo wo type karo).
  • 'search ...' me -> App start block se browser kholo (Google ka URL).

Pehle 2-3 command banao aur test karo. Jab chal jaye, aise hi naye commands add karte jao — har naya command ek chhoti practice hai.

Level 3 — Jahan bolu, wahan click

Kahin bhi click karne ke liye 'Interact touch' block use hota hai — usme X aur Y coordinates dete hain (screen ke percent me). Coordinates jaanne ke liye: phone ki Developer options me 'Pointer location' ON karo, phir jahan touch karo wahan X,Y dikh jayega.

Kisi button ko uske naam se click karna ho to 'Interact' block use karo (XPath ke saath). Automate me 'Record interaction' button hai jo apne aap XPath bana deta hai.

Kuch jagah automation kaam nahi karega — jaise banking apps, password ke boxes, ya protected video. Ye Android ka niyam hai, koi bug nahi.

Level 4 — AI email (khud likhe, kuch pooche)

Ye sabse mazedaar hissa hai. Flow aisa hoga:

Bolo 'email bhejo'  >  Dialog input: kisko bhejna hai?  >  Dialog input: kya likhna hai / points batao  >  HTTP request (Gemini)  >  Dialog confirm: draft dikhao, 'bhej doon?'  >  Send email
  • HTTP request block: Method POST, URL Gemini ka endpoint, header Content-Type: application/json. Body me apna prompt bhejo jaise: Write a short polite email on these points: {points}
  • Response me se email ka text nikaalo: candidates[0].content.parts[0].text (Automate me HTTP response ko dictionary me parse karke).
  • Send email block: subject aur draft body daal ke bhejo.
Zaroori: email bhejne se PEHLE draft dikhao aur 'bhej doon?' poocho (Dialog confirm). Bina poochhe kabhi auto-send mat karo — galti se galat email na chala jaye.

Ready-made flows se shuruaat

Automate ki community me log apne banaye flows share karte hain — llamalab.com/automate/community. Wahan 'Voice Typing' jaisa flow mil jayega jise import karke aap turant voice-to-type kar sakte ho, aur usme apna kaam jodte ja sakte ho.
